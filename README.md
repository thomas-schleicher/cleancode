# Description
This project is a simple web crawler implemented in Java, designed with a strong focus on clean code principles. The architecture emphasizes abstraction, design patterns, and software design principles to ensure readability, maintainability, and scalability.

# How to Use

As this project uses gradle you can use the gradle commands to build, test, and run this project.
Make sure you are in the project directory and execute the action you want using the following commands:

```bash
  gradle build
```
```bash
  gradle test
```
```bash
  gradle run
```
